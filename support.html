Game support

Co-op and friends

On the host device, open Co-op and host a game. On the other device, open Co-op and join with the lobby code for internet play. For LAN play, connect both devices to the same Wi-Fi network and allow Local Network access when iOS asks. Some networks block direct connections. If an internet lobby cannot connect, try a different network.

Purchases

When purchases are available, open Armory → BANK. Use Restore Purchases there to recover eligible one-time purchases with the Apple Account used to buy them. Consumable crystal packs cannot be restored. For billing questions or refunds, use Apple’s purchase support.

Contact Eclipse Studio

Open a GitHub issue and include your device model, iOS or iPadOS version, game version, and the steps that led to the problem. Issues are public. Keep payment information, receipts, email addresses, Apple Account details, and private identifiers out of the issue. For a privacy request, open an issue titled “Privacy request” and ask for a private follow-up before providing identifying details.
